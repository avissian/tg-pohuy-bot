# tg-pohuy-bot

Telegram-чат-бот — тонкий клиент до LLM API с языковым скиллом pohuy.

## Архитектура

- **Тонкий клиент**: у модели нет tool-вызовов, файлового доступа и сети.
  Бот умеет только принимать сообщения, ходить в LLM API и отвечать.
- **Whitelist до модели**: `ALLOWED_CHAT_IDS` проверяется тупым кодом
  до любого обращения к модели. Чужие чаты отбрасываются молча (с записью в лог).
- **История диалогов**: sqlite в `./data`, контекст последних
  `HISTORY_DEPTH` сообщений. `/reset` очищает историю чата.
- **Скилл**: файлы из `skills/pohuy/` вшиваются в системный промпт при старте.

## Переменные окружения

См. `.env.example`. Обязательны: `TELEGRAM_BOT_TOKEN`, `ALLOWED_CHAT_IDS`,
`LLM_API_BASE`, `LLM_API_KEY`.

## Запуск

```sh
cp .env.example .env  # заполнить
docker compose up -d --build
docker logs -f tg-pohuy-bot
```

## Изменение whitelist

Отредактировать `ALLOWED_CHAT_IDS` в `.env`, затем `docker compose up -d`.
Изменение применяется только вручную — модели недоступно управление доступом.

## Безопасность

- Секреты в контейнере: только токен бота и ключ LLM API.
  Они не дают доступа к какой-либо инфраструктуре.
- Исходящие соединения: api.telegram.org и LLM API. Published-портов нет.
- Компрометация токена бота раскрывает переписку, но не исполняет код.
